# Prueba_actividad_postman
# Pruebas de API E-Commerce – FakeStoreAPI (Postman)

Repositorio con la colección de pruebas de integración, especificación de contrato OpenAPI 2.0 y documentación de evidencias aplicando los 4 verbos HTTP (`GET`, `POST`, `PUT`, `DELETE`) sobre **FakeStoreAPI**.

* **Autor:** Jolaus Andy Meza Pérez
* **Herramienta:** Postman (OpenAPI 2.0 Spec, Variables de Entorno y Scripts Post-response)
* **API Base:** `https://fakestoreapi.com`

## Contenido del Repositorio

* `ActividadRetoJAMP.postman_collection.json`: Colección exportada con las peticiones CRUD y scripts de validación.
* `index.yaml`: Contrato técnico de la API definido bajo el estándar OpenAPI 2.0.
* `Pruebas Api Postman.docx`: Informe detallado con las capturas de ejecución de cada endpoint.
